SISTEMA DE CAJA - MINIMARKET
============================

Es una copia del sistema Bonanza (minimarket y bodega en una misma caja),
pero con nombre "Minimarket", logo propio y DATOS SEPARADOS: tiene su propio servidor,
así no se mezcla con Bonanza ni con Bodega BG. Empieza limpio, sin ventas de ejemplo.

USUARIOS INICIALES
- Administrador: admin / admin123
- Cajero:        caja  / 1234
Cámbielas apenas entre (toque su nombre arriba a la derecha > Mi perfil).
En Configuración se cambian el nombre del minimarket, de la bodega, dirección, RUC, etc.

DIRECCIONES
- Página: https://minimarketspycomers.spynetpy.com
- Datos:  https://api-minimarketspycomers.spynetpy.com/api.php

PASO 1 - SERVIDOR DE DATOS (cPanel)
1. Domains > Create A New Domain > api-minimarketspycomers.spynetpy.com > Submit.
2. Haga clic en la carpeta del dominio nuevo > Upload > suba el api.php
   que está en la carpeta "2-subir-al-cPanel".
3. Pruebe: https://api-minimarketspycomers.spynetpy.com/api.php
   Debe mostrar {"ok":false,"error":"Acción desconocida"}
   (si dice "conexión no privada", espere unos minutos al certificado).

PASO 2 - LA PÁGINA (GitHub)
1. Cree un repositorio nuevo, por ejemplo invitamos/minimarketspycomers.
2. Abra en VS Code SOLO la carpeta "1-subir-a-GitHub" y en la terminal:
     git init
     git add .
     git commit -m "Minimarket"
     git branch -M main
     git remote add origin https://github.com/invitamos/minimarketspycomers.git
     git push -u origin main
3. GitHub > Settings > Pages > Branch: main / (root) > Save.
   Custom domain: minimarketspycomers.spynetpy.com > Save.

PASO 3 - EL LINK (cPanel > Zone Editor > spynetpy.com > + Add Record)
   Name: minimarketspycomers   Type: CNAME   Record: invitamos.github.io
   Cuando GitHub muestre el tilde verde, marque "Enforce HTTPS".

PASO 4 - INGRESAR
   Abra https://minimarketspycomers.spynetpy.com e ingrese con admin / admin123.
   Arriba debe decir "Sincronizado".

PARA ACTUALIZAR GITHUB MÁS ADELANTE
     git pull --no-edit
     git add .
     git commit -m "Actualización"
     git push
